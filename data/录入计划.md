# 历史星图 · 二十四史数据录入总计划

## 一、录入原则

1. **按正史顺序**：史记 → 汉书 → 后汉书 → 三国志 → 晋书 → … → 明史
2. **按人物重要性**：本纪 → 世家 → 列传 → 表/书（仅提取关键人物）
3. **每批 5-10 人**：便于审核、提交和部署
4. **每次提交附史书来源**：便于追溯和校验

## 四、录入标准

### 必录字段
- `id`：唯一标识
- `name`：姓名
- `dynasty`：所属朝代
- `short`：短简介
- `sources`：至少 1 条 A 级史料来源

### 推荐字段
- `born` / `died`：生卒年（尽可能精确）
- `life`：生平事件线（至少 5 个关键节点）
- `achievements`：主要成就
- `relations`：至少 1 条人物关系
- `events`：参与的重大事件

### 质量标准
- 每个字段必须有史料依据
- 来源等级标注清晰（A/B/C/D）
- 生卒年优先使用正史记载，存疑时标注
- 争议内容需客观呈现，注明不同观点来源

## 五、执行流程（每批）

```
1. 按当前批次创建 JSON 文件
2. 运行 node scripts/seed-data.js（合并全部数据）
3. 验证：sqlite3 history-atlas.db "SELECT COUNT(*) FROM persons;"
4. git add data/ history-atlas.db
5. git commit -m "data: 添加《史记·XXX》人物（批次N）"
6. git push origin main
7. 等待 Render 自动部署（约 2-3 分钟）
8. 验证后端：curl https://history-atlas-api.onrender.com/api/persons
9. 复制 website/data.js → website-deploy/data.js
10. git commit -m "data: sync frontend data"
11. git push origin main
```
